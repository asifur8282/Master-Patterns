# 🌌 Master Patterns — CS Pattern Learning & Interactive Visualizer

> An aesthetic, interactive educational web platform designed to help Computer Science students master nested loops, pattern printing, dynamic symbol customization, and multi-language implementations visually.

---

## ✨ Features

- 🎯 **Comprehensive Pattern Library**: Catalog of classic CS patterns (Star Pyramids, Right Triangles, Diamonds, Floyd's Triangle, Pascal's Triangle, Continuous Alphabets, Butterfly Patterns, and Hollow Shapes) with unique IDs (`ast_001`, `num_001`, `chr_001`, etc.).
- 🎛️ **Interactive Pattern Lab**:
  - **Quick Action Controls**: `Increase Rows (+)`, `Decrease Rows (-)`, `Increase Space (+)`, and `Decrease Space (-)`.
  - **Direct Row Input**: Fine-tune pattern height directly via numerical input or range slider.
  - **"Change your Symbol"**: Real-time custom symbol replacement (swap default `*` for `%`, `@`, `#`, `🐱`, `A`, or any multi-character string).
- 💻 **"Get Code" & Line-by-Line Interactive Explanations**:
  - Generate source code dynamically in **C**, **C++**, **Java**, **Python**, and **JavaScript**.
  - **Clickable Line Breakdown**: Click any line of code to see an instant educational breakdown explaining *how* that line connects to outer loops, inner spaces, character printing, and line breaks.
- 🎞️ **Step-by-Step Execution Visualizer**:
  - Interactive playback player with Play/Pause animation and step slider to watch patterns render row-by-row.
- 🌙 **Dark & Light Themes**: Powered by Google Sans & Poppins fonts with modern glassmorphism UI.

---

## 🛠️ Tech Stack

- **Framework**: React 18 + Vite
- **Styling**: Vanilla CSS with CSS Custom Properties, Glassmorphism, and Responsive Layouts
- **Icons**: Lucide React
- **Fonts**: Poppins, Inter / Google Sans, Fira Code

## 🚀 Quick Start

1. **Clone the repository**:
   ```bash
   git clone https://github.com/YOUR_USERNAME/master-patterns.git
   cd master-patterns
   ```

2. **Install dependencies**:
   ```bash
   npm install
   ```

3. **Run the local development server**:
   ```bash
   npm run dev
   ```

4. **Build for production**:
   ```bash
   npm run build
   ```
